## 1. 逐条改动

### A1「开始跑步」进首屏（选了「提到地图之前」，没做底部固定栏）

- **改了什么**：把「方案摘要 → 取消按钮 → 主操作行（开始跑步 + 换一版）」整体移到 `draw_run_map(ui)` **之前**；
  只搬了一行调用（`self.draw_run_map(ui)` 从按钮块前挪到块后），没有改任何提交路径。
- **为什么不选 sticky 底栏**：`run` 页的滚动容器是 `ScrollArea`，egui 没有内置 sticky；自绘固定栏要额外维护
  一份「当前可视区」状态，且会永久吃掉矮屏 44 px（640×360 的页面可视区只有 176 px），与 A1 的目的相反。
- **心智顺序**：`参数 → 方案摘要（距离/配速/用时/开始时刻，就是「确认轨迹」的文本版）→ 开始跑步 → 下方地图复核`。
  预览没生成时按钮旁常显「（下方地图暂无路线预览）」，不隐藏按钮（隐藏会让人不知道能不能点）。
- **为什么不丢功能**：`enabled = !run_busy && session.is_some()`、`start_run()`、`取消准备/轨迹生成` 全部原样；
  测试侧无依赖（`grep 开始跑步` 只命中 `run.rs` 的按钮文案与注释）。

### A2 底图工具条折叠（`tiles::toolbar`，跑步页 ×2 调用点 + 路网页共用）

- 收起后只剩 **一行**「底图：关 / 高德 / OSM」+ **一个** `CollapsingHeader("底图缓存与坐标系说明")`（默认收起）。
- 缓存占用、`清理缓存`、坐标系说明进折叠区；返回 `changed` 的语义不变（调用方照旧落盘）。

### A3 去掉底栏重复的「检查更新」

- `mod.rs` 底栏只留版本号；「检查更新」唯一入口是「关于」页。紧凑模式底栏本来就不画它，现在两种形态一致。

### A4 设备页「保存 / 撤销修改」上移

- 从 8 个输入框之后（360×640 下纸面下 174 px）移到平台选择那一行（进页面即首屏）。
- 保存逻辑抽成 `App::save_device_identity(&mut self, page)`，逐字照搬（机型变化重置派生指纹、失败弹窗不变）。
- 表单字段一行没删，停手自动保存（`autosave_location`）不动。

### A5「高级生成参数」折叠

- 手动海拔 / GPS 抖动 / 锚点偏移 / 固定种子 / 人脸校验标记（faceCheck）收进
  `CollapsingHeader("高级生成参数（不填即用默认值）")`，默认收起。
- 五组控件全部保留、默认值语义不变（0/空 = 旧行为）；`RunSettings` 快照与落盘逻辑没动。

### A6 数据页「违规自查」「排行榜」默认收起

- 只改两个 `.default_open(true) → false`；「学期完成度」保持展开。
- 首屏控件 8 → 5；里面每个按钮（立即检查 / 查看列表 / 查询）都还在，点开标题一次即可达。

### A7 路网页「取路网」四按钮 → 一个状态机按钮 + 一个开关

- 主按钮按状态变名：空闲「自动获取学校路网」/ busy「取消获取路网」/ 失败后「重试获取路网」；
  旁边一个 `toggle_value("强制重新下载")`（始终渲染，手动文件模式下置灰）承接原「重新下载路网」。
- `OsmPage` 新增两个**纯 UI 状态**：`retry_available`（失败或取消后置真，开始新加载置假）、`force_reload`（一次性，点完即复位）；
  `msgs.rs` 在成功/失败分支各写一次 `retry_available`。请求与状态机逻辑未改。

### A8「启动时检查更新」三选一 → 下拉

- 三个 18 pt 单选 → 一个 `ComboBox`；写的是同一个 `config.update_check`，落盘分支不变。
